## Самостоятельные доработки

В ходе выполнения контрольной работы №2 базовый проект был существенно расширен:

- **Локальное подключение Bootstrap:** фреймворк подключён без использования CDN, файлы размещены в папке `vendor/bootstrap/`.
- **Разработка дизайна (тёмная тема):** проведена работа над визуальным стилем сайта. С помощью utility-классов (`bg-dark`, `text-light`, `bg-secondary`, `bg-gradient`, `bg-opacity-*`, `shadow-lg`) реализована целостная тёмная тема.
- **Расширение структуры:** вместо одной страницы товара созданы три отдельные страницы (`product1.html`, `product2.html`, `product3.html`) для разных категорий спортивного питания.
- **Улучшение карточек:** добавлены тематические изображения, бейджи позиционируются поверх карточек через `position-absolute top-0 end-0`. Для акционного товара старая цена перечёркнута с помощью тега `<s>`.
- **Кастомизация `custom.css`:** реализовано прижатие футера к низу экрана, стилизация заглушек изображений, а также точечная настройка переменных Bootstrap (цвет разделителя в `breadcrumb`, кастомный класс прозрачности `.bg-opacity-90`).
